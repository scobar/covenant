# PX-001 — Zero-Budget Micro-Pilot Readiness Checklist

> **DRAFT ZERO-BUDGET EXTERNAL-REVIEW MICRO-PILOT PLAN v0.1 — NONCANONICAL — NO REVIEWER OR MODEL SELECTED**

## Plan-Only Boundary

PX-001 defines an optional process micro-pilot only. It may remain dormant
indefinitely without blocking the project. No human volunteer or external model
must become available, and failure to obtain either optional unit is not a
project failure. The plan creates no entitlement to anyone's unpaid labor and
no obligation for Scott to spend money.

This checklist does not select or contact anyone; select or run a model;
assemble a packet; create a mapping, nonce, or commitment; execute or publish a
review; or create candidate preference. A later accepted decision is required
before any invitation, model selection, packet assembly, or execution. Any
later external review would remain bounded criticism—not moral authority,
representativeness, consensus, canonicality, or superintelligence assent.

PX-001 plans at most two independently optional paired units:

- At most one `Uncompensated volunteer human-unassisted micro-review`, with
  voluntary, informed, low-pressure, revocable participation.
- At most one `Zero-incremental-cost external-model micro-review`, using an
  unselected non-OpenAI provider and model.

Each possible unit evaluates Candidate A and Candidate B separately before
comparison, uses one frozen scenario, and uses the short micro-review form.
Neither unit has a waitlist, replacement requirement, or completion minimum.
Either may later be authorized without the other. One completed unit would be
one bounded process datapoint—not a pilot-success verdict or
candidate-preference signal. If neither becomes available, PX-001 remains a
dormant plan.

The human unit is not a paid professional review, representative public
opinion, or an independent scientific study. The model unit does not establish
external evaluator diversity merely by using a different provider. The short
form is not a complete fifteen-dimension ERX-001 review and does not satisfy
D-009, which remains `Proposed`.
