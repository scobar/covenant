verdict or candidate-preference signal. Use of a different provider would not
by itself establish external-evaluator diversity. If neither unit becomes
available, PX-001 remains a dormant plan.

## Exact three-context architecture

The paired model unit requires exactly three fresh contexts, in this order:

1. Start a fresh context for Candidate A.
2. Freeze the Candidate A output.
3. Start a fresh context for Candidate B.
4. Freeze the Candidate B output.
5. Start a third fresh context for comparison.

The third context begins only after both candidate-specific outputs freeze.
Each candidate-specific context remains isolated from the other candidate and
its response. No candidate-specific context receives:

- The other candidate.
- The other candidate-specific response.
- Candidate lineage.
- Existing project outcomes.
- A target conclusion.
- A winner request.

Each candidate-specific context would use the same short micro-review form and
the same single neutral-labeled scenario. The third fresh context would receive
only the later-authorized comparative materials after both candidate-specific
outputs freeze. No context exists and no output has been frozen in this task.

## Technical-invalidity retry rule

Permit at most one retry for a context, and only for technical invalidity.
Technical invalidity is limited to:

- Provider or transport failure.
- Truncation before the required response sections.
- Wrong packet delivery.
- Inability to preserve the output.
- Evidence that prohibited prior material contaminated the context.

Do not retry merely because the model:

- Refuses for substantive reasons.
- Produces an indeterminate result.
- Criticizes the project strongly.
- Finds no candidate preferable.
- Recommends stopping.
- Produces an unexpected outcome.

The one permitted retry does not authorize output selection. Preserve the
invalid or failed attempt and the retry, together with the technical basis for
the retry. If the permitted retry also fails, mark the optional unit incomplete
and defer it. Do not silently choose another provider.
