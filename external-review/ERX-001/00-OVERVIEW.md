# ERX-001 — Neutral External-Review Preparation Package

**DRAFT EXTERNAL-REVIEW PREPARATION PACKAGE v0.1 — NONCANONICAL — NO REVIEW EXECUTED**

Only package preparation is authorized. Reviewer assignment, review execution,
submission freezing, unblinding, publication, result integration, and any
candidate-preference decision are separate future stages requiring separate
authorization.

No reviewer has been recruited, assigned, or contacted. No label mapping has
been created or committed. No review has been executed, no response exists,
and no candidate preference exists. This package is not an evaluation.
Preparing or publishing it does not imply acceptance of either candidate or
of the Covenant. Any later external review would remain bounded evidence, not
moral authority, representativeness, consensus, or canonicality.

## Purpose

ERX-001 prepares a reproducible, disclosure-rich process for later external
criticism of two exact, noncanonical candidates before any
comparative-preference decision. It separates source identity, assignment,
review, response freezing, unblinding, publication, and result integration so
that later evidence can remain traceable without becoming authority.

## Why the Package Exists

CR-001 recommends external review because all current substantive reviews
remain within the same broad tooling family and shared project framework.
ERX-001 prepares a method for receiving criticism from outside that existing
review process without prejudging what the criticism should conclude.

## Package Modes

### 1. Single-Candidate Review

- A reviewer sees one procedurally labeled candidate.
- No comparative judgment is requested.
- The mode is useful for candidate-specific external evidence.

### 2. Paired Matched Review

- Candidate-specific review is completed and frozen separately for each
  procedurally labeled candidate.
- Comparison occurs only afterward.
- Candidate order and scenario order are preassigned and recorded.
- No winner is requested.

### 3. Human Track

Human-unassisted and human-AI-assisted work are separate method classes. Their
disclosures and provenance must remain distinct.

### 4. Model Track

Each candidate-specific review uses a fresh context. A later comparison uses a
third fresh context. Same-provider or same-family repetitions are not
independent diversity.

## Procedural Label Blinding

ERX-001 uses **procedural label blinding** to reduce version-label, recency, and
declared-successor cues within a supplied packet. Reviewer-facing materials use
neutral packet-local candidate and scenario labels, opaque packet IDs, and an
opaque packet-instance commitment. Canonical candidate and scenario mappings
remain in administrator-only records outside the repository during active
review and may be disclosed only after applicable responses freeze and later
authorization permits unblinding.

The packet commitment is a future precommitment to exact mapping-record bytes;
it is not a candidate hash and does not reveal the mapping by itself. No actual
mapping, mapping record, nonce, commitment, packet, or assignment exists in
this preparation task.

These measures do not guarantee ignorance. The repository is public, and exact
candidate and scenario text remains publicly discoverable. A reviewer could
identify a source through prior familiarity, independently hashing or comparing
text, exact-phrase or identifier search, repository browsing, or outside
lookup.

Reviewers must disclose prior exposure, repository browsing, outside lookup,
independent hashing or text search, or an inferred mapping. Exposure does not
automatically invalidate a response, but it changes the response's method
classification.

## Package Boundaries

- ERX-001 contains templates and protocols only.
- Canonical source files are not duplicated in the repository.
- Actual reviewer packets must be assembled later from exact canonical bytes.
- Source materials, assignment mappings, and responses retain separate
  provenance.
- Package creation changes no result, candidate status, or preference.
- No packet has been assembled and no pilot has been authorized.
- No reviewer identity, invitation, response, consent record, external result,
  or publication record is created here.
