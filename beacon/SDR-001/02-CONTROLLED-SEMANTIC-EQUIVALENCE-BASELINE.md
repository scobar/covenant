# SDR-001 — Controlled Semantic-Equivalence Baseline

> **SDR-001 v0.1 — NONCANONICAL SUCCESSOR-DESIGN RESEARCH — NO SIG-002 ATTEMPT, STREAM, HOLDOUT, OR MODEL TRIAL**

## Definitions

- **Semantic equivalence:** preservation of the same abstract semantic graph,
  curriculum, truth assignments, roles, arities, examples, queries, validity
  rules, and scoring meaning across a future pair, independent of surface
  realization.
- **Surface novelty:** use of newly generated, unrevealed surface values for
  every future sealed test artifact while preserving the shared abstract
  source.
- **Framing cue:** an abstract event pattern whose assigned function marks or
  helps infer an outer boundary, body, section, block, record, atom, header,
  expression/result distinction, or other framing role.
- **Framing-cue multiset:** the complete bag of framing cue patterns with their
  multiplicities, ignoring placement but preserving every cue instance and
  pattern count.
- **Framing-event budget:** the total count of events assigned to framing cues
  in one condition.
- **Nonframing content:** every event byte and abstract content relation not
  assigned to framing.
- **Global-concentrated framing:** framing information located primarily in
  global headers, outer boundaries, and hierarchical delimiter placement.
- **Locally repeated boundary-role framing:** the same framing-cue multiset
  redistributed so equivalent boundary-role information recurs adjacent to
  the local units it frames.
- **Single-variable isolation:** a paired comparison in which framing-cue
  placement or locality is the only manipulated design dimension.

No definition selects an exact value, symbol, byte, delimiter, header,
sentinel, example, query, or stream.

## Eighteen controlled invariants

A future baseline/treatment pair must preserve all eighteen unless a later
accepted decision explicitly changes one:

1. Two distinguishable event classes.
2. Total-order carrier-neutral event model.
3. Decoder Levels 0–4 only.
4. Same abstract seven-section curriculum.
5. Same abstract record, block, section, and duplicate-body counts.
6. Same quantity domain and structured-numeracy curriculum.
7. Same equality, order, addition, multiplication, Boolean, and prefix
   expression semantics.
8. Same truth orientation.
9. Same token-role semantics and arities.
10. Same fourteen example meanings.
11. Same seven query meanings.
12. Same duplicate-body policy.
13. Same neutral instruction.
14. Same valid/invalid/contamination rules.
15. Same categorical nonaggregate scoring philosophy.
16. Same public/private chronology.
17. Same exposure-stratified reporting.
18. Surface novelty for every future sealed test artifact.

The exact surface values and event bytes remain unselected.

## Future equivalence proof checklist

- [ ] One frozen abstract semantic source generates both conditions.
- [ ] All eighteen invariants are mapped field by field.
- [ ] The semantic graphs and truth assignments are identical.
- [ ] Record, block, section, example, query, and duplicate-body counts match.
- [ ] Nonframing event bytes are byte-identical.
- [ ] The framing-cue multisets are identical, including multiplicity.
- [ ] Total framing-event counts are identical.
- [ ] Only cue placement or locality differs.
- [ ] Both conditions have a unique intended abstract parse.
- [ ] Any stream-length or parse-complexity difference is eliminated or
  disclosed before freeze.
- [ ] Surface novelty and exposure classification are established separately.
- [ ] A scratch audit reproduces the proof before stream creation.

## Stop conditions

Stop and return to design research if any invariant cannot be shown, the cue
multisets or framing-event budgets differ, nonframing bytes differ, parse
uniqueness fails, an exact value must be chosen inside SDR-001, or more than
one primary variable is needed. Such a pair must not be called a locality-only
experiment.
