# SDR-001 — Decision Basis and Traceability

> **SDR-001 v0.1 — NONCANONICAL SUCCESSOR-DESIGN RESEARCH — NO SIG-002 ATTEMPT, STREAM, HOLDOUT, OR MODEL TRIAL**

## Evidence boundary

This record traces a controllable research choice to frozen public evidence.
It does not turn a diagnostic classification into causal proof, replace the
frozen result, disclose private evidence, or erase preserved dissent.

## Evidence-to-selection matrix

| Frozen public evidence | Bounded design implication | What it does not establish |
| --- | --- | --- |
| Level 0 artificiality recovered. | Preserve artificiality as a nonregression guardrail. | Artificiality recovery does not prove the framing design is adequate. |
| Level 1 framing was not recovered. | Make framing/hierarchy recovery the primary comparative endpoint. | Nonrecovery does not identify one cause. |
| Level 2 numeracy was partially recovered. | Preserve structured numeracy as a nonregression guardrail. | Complete framing is not shown to be necessary for all quantity recovery. |
| Delimiter-versus-data separation was a `Supported` diagnostic site. | Study whether locality changes role legibility while keeping cue strength fixed. | The status is not a decoder score or proof of causation. |
| Boundary-hierarchy ordering was a `Supported` diagnostic site. | Compare global concentration with local boundary-role recurrence. | No exact delimiter pattern is selected. |
| Header or sentinel interpretation was a `Supported` diagnostic site. | Keep abstract header roles fixed while studying placement. | No header or sentinel value is selected. |
| Local-to-global integration was a `Supported` diagnostic site. | Test whether locally adjacent role information affects global hierarchy recovery. | Local repetition is not proven beneficial. |

## Methodological limitations retained

- The valid result is prior-exposed and eligible only for
  exposure-stratified reporting.
- Same-provider independence is not established.
- Displayed provider/model labels do not verify the hidden backend.
- Incognito is a limited interface control, not proof of provider isolation.
- DA-001 is same-tooling and post-hoc.
- Browser-copy and hidden platform-state limitations remain.
- Five family-status disagreements and additional scope dissent remain
  preserved privately.

These limitations prevent locality from being declared the cause. Locality is
selected because it is a relevant, controllable variable that can be isolated
under semantic and cue-budget equivalence.

## Alternatives and disposition

| DA-001 experiment class | Disposition | Reason |
| --- | --- | --- |
| 1. Boundary-redundancy strength | Deferred manipulated variable | A redundancy change would alter cue count or strength and confound locality. |
| 2. Local versus global framing | Selected as primary | It directly expresses one placement variable while preserving the cue multiset and semantic source. |
| 3. Explicit versus emergent section differentiation | Deferred manipulated variable | Section differentiation must remain fixed in a locality-only comparison. |
| 4. Duplicate-body cue presence versus ablation | Deferred manipulated variable | Duplicate-body policy remains invariant and its recognition failure is contradicted as the explanation. |
| 5. Fixed framing with varied arithmetic teaching | Deferred manipulated variable | Arithmetic teaching remains fixed and Level 2 is a guardrail. |
| 6. Fixed grammar with varied query marking | Deferred manipulated variable | Grammar and query marking remain fixed; Levels 3 and 4 are exploratory only. |
| 7. Provider-independent replication | Retained replication requirement | It tests provider dependence separately and must not vary between paired conditions. |
| 8. Clean no-known-exposure holdout testing | Retained contamination requirement | It strengthens validity separately and is not a framing treatment. |

## Selection conclusion

The frozen evidence warrants a controlled locality question, not a causal
verdict. Any future exact pair that changes cue count, cue strength, semantic
content, arithmetic teaching, grammar, query marking, event-class count,
duplication, provider, or another primary variable must be classified as
confounded or not comparable and must return to design research.
